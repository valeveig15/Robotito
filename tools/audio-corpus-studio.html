Preparar una grabación para evaluar sonidos

¿Querés comprobar permisos y nivel de entrada sin grabar sonido? Abrí el diagnóstico privado del micrófono. Es una prueba distinta: no reemplaza la evaluación de reconocimiento acústico.

Privacidad: todo se procesa en este navegador. No se envía audio, etiquetas ni información personal a ningún servidor. La grabación solo empieza cuando presionás «Grabar» y autorizás el micrófono. Esta herramienta no descarga modelos ni activa reacciones del avatar.

1. Elegí un audio

Podés importar un audio autorizado o grabar uno nuevo con tu micrófono. Usá un solo archivo por manifiesto.

Todavía no hay un audio cargado.

2. Identificá la fuente sin datos personales

Evitá nombres, números de serie y datos personales en los identificadores. No uses la partición «prueba» para ajustar umbrales.

3. Marcá sonidos e intervalos suprimidos

Los segundos son relativos al comienzo del audio. Una sesión sin eventos anotados también sirve para medir falsas alarmas en ruido de fondo, siempre que hayas comprobado que no contiene los eventos buscados.

    Los intervalos suprimidos no se envían al clasificador: marcá allí voz propia de Robotito, Modo Clase u otros tramos que no deban evaluarse. No pueden solaparse con sonidos anotados: corregí una de las marcas para evitar resultados contradictorios.

      4. Descargá audio y manifiesto

      Se crean dos archivos locales: <id>.<extensión> y manifest-<id>.json. Guardalos en la misma carpeta para que las rutas relativas funcionen.

      Para unir varias grabaciones independientes sin copiar ni subir audio, organizalas en carpetas bajo una carpeta común y ejecutá npm run assemble:audio -- /corpus/combinado.json /corpus/sesion-a/manifest-a.json /corpus/sesion-b/manifest-b.json. Las etiquetas, derechos y grupos se verifican nuevamente antes de crear el manifiesto combinado. Las sesiones en borrador no podrán evaluarse.

      Para saber qué evidencias faltan antes de calibrar los cinco eventos, ejecutá npm run audit:audio:p03 -- /corpus/combinado.json --field /corpus/prueba-microfono.json (el argumento --field es opcional). El informe es solo un inventario de cobertura, sin datos personales ni autorización para reacciones automáticas.

      Antes de evaluar, ejecutá npm run validate:audio -- /ruta/manifest-sesion-001.json. Después podés ejecutar npm run evaluate:audio -- /ruta/manifest-sesion-001.json. El evaluador sigue sin autorizar automáticamente reacciones.
